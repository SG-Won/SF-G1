# wireframe 스킬 / Build one screen on your branch

사용자가 만들고 싶은 **한 화면**을 받아 단일 HTML 파일로 빠르게 만든다.
(영어 안내가 필요하면 한국어 옆에 함께 적어 준다.)

## 단계 (Steps)
1. **무엇을·누구를 위해·핵심 요소 3가지**를 각각 한 줄로 확인한다. 모호하면 가장 합리적인 해석을 택하고 가정을 한 줄로 밝힌다.
2. 아래 **공통 디자인 규칙**을 적용해 `index.html` 한 파일을 만든다. (이미 있으면 내용을 확인하고 개선해 덮어쓴다.)
3. 핵심 동작(버튼·입력·상태 변화)이 **실제로 작동**하게 한다. 데이터 저장이 필요하면 `localStorage` 사용.
4. **지금 체크아웃된 브랜치 그대로** 커밋·푸시한다. (`git checkout`으로 브랜치를 바꾸지 말 것 — 각자 자기 브랜치에서 작업한다.)
5. 마지막에 무엇을 만들었는지 1~2줄로 요약하고, 미리보기 방법을 알려 준다.

## 공통 디자인 규칙 (Design rules)
- 외부 라이브러리·CDN·웹폰트 **금지**. 시스템 폰트만: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`
- 색: 배경 `#f6f7fb`, 카드 `#ffffff`, 강조 `#4f46e5`(남용 금지), 본문 `#1f2433`, 보조 `#6b7280`, 테두리 `#e5e7eb`
- 모서리 12~16px, 부드러운 그림자, 넉넉한 여백, 모바일·데스크톱 **반응형**
- **한국어 UI**, 버튼·입력은 실제로 동작
- **단일 자기완결형 HTML 파일**(CSS·JS 인라인), 외부 의존성 없음

# prototype 스킬 / Idea → design thinking → prototype

제품 아이디어 한 줄을 받아 **디자인씽킹 흐름**으로 작동하는 프로토타입을 만든다.
각 단계 결과를 사용자에게 짧게 보여 주고 다음으로 진행한다.

## 1단계 — 문제·타겟 페르소나 (공감·정의)
- 아이디어를 한 문장으로 재진술한다.
- 해결할 **핵심 문제**를 1~2문장으로 정의한다.
- **타겟 페르소나 1명**: 이름·상황·니즈·페인포인트.

## 2단계 — 핵심 기능 우선순위 (수렴)
- 핵심 기능 **3개**를 뽑아 **P1·P2·P3** 우선순위와 이유를 한 줄씩.
- P1을 프로토타입의 중심 흐름으로 삼는다.

## 3단계 — 프로토타입 생성
- 아래 **공통 디자인 규칙**으로 단일 `index.html`(또는 `prototypes/<슬러그>.html`)을 만든다.
- P1 기능이 **실제로 동작**하게 한다(필요하면 `localStorage`).

## 4단계 — 새 브랜치에 커밋·push
- `prototype-<슬러그>` 새 브랜치를 만들어 커밋하고 `origin`에 push한다.

## 5단계 — 마무리 안내
- 미리보기 방법과 **다음 단계(사용자 테스트)**를 한두 줄로 제안한다.

## 공통 디자인 규칙 (Design rules)
- 외부 라이브러리·CDN·웹폰트 **금지**. 시스템 폰트만: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`
- 색: 배경 `#f6f7fb`, 카드 `#ffffff`, 강조 `#4f46e5`(남용 금지), 본문 `#1f2433`, 보조 `#6b7280`, 테두리 `#e5e7eb`
- 모서리 12~16px, 부드러운 그림자, 넉넉한 여백, 모바일·데스크톱 **반응형**
- **한국어 UI**, 버튼·입력은 실제로 동작
- **단일 자기완결형 HTML 파일**(CSS·JS 인라인), 외부 의존성 없음

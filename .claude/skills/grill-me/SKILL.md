# grill-me 스킬 / 5-question idea sharpener

막연한 아이디어를 **짧게** 구체화한다. 비개발자를 위한 도구이므로 친근하고 쉽게 묻는다.

## 규칙 (중요)
- **질문은 최대 5개.** 한 번에 **하나씩**, 짧고 구체적으로 묻고 답을 기다린다.
- 답이 모호하면 **딱 한 번** 더 짧게 되묻되, 전체 질문 수는 5개를 넘기지 않는다.
- 코드·전문 용어를 쓰지 않는다. 예시를 한 줄 곁들여 답하기 쉽게 한다.
- 사용자가 "그냥 만들어줘" 라고 하면 즉시 질문을 멈추고, 합리적인 가정으로 브리프를 채운다.
- 영어가 필요하면 한국어 옆에 짧게 덧붙인다.

## 5개 질문 (하나씩)
1. **누구를 위한 건가요?** 한 사람만 구체적으로. (예: "혼자 사는 강아지 주인")
2. **그 사람의 어떤 불편을 해결하나요?** 한 문장. (예: "산책 친구를 못 찾음")
3. **그 사람이 할 수 있는 가장 중요한 한 가지 행동은?** (예: "근처 산책 메이트 찾기") — 이게 P1.
4. **첫 화면에 뭐가 보여야 하나요?** 입력/버튼/결과 등 2~3개. (예: "동네 선택 → 메이트 목록")
5. **느낌·스타일은?** 한 단어로 충분. (예: "친근하고 따뜻한", "깔끔하고 전문적인")

## 마무리 — 제품 브리프 출력
5개 답(또는 가정)을 모아 아래 형식으로 **짧게** 정리해 보여 준다:

```
## 제품 브리프
- 타겟 유저: ...
- 해결할 문제: ...
- P1 핵심 기능: ...
- 첫 화면 요소: ...
- 스타일: ...
```

그다음 한 줄로 안내한다: "이대로 만들까요? `/wireframe` 또는 `/prototype` 로 바로 만들 수 있어요. (수정할 곳이 있으면 말씀해 주세요.)"
